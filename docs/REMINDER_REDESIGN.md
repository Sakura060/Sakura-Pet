# 绘梨衣提醒系统 v2.0 — 设计文档

## 一、交互流程

```
用户创建提醒
  ├── 右键菜单 → 快速预设（喝水/休息/会议/吃药/自定义）
  ├── 聊天窗口输入"30分钟后提醒我开会" → 语音解析
  └── 设置页 → TodoService.Add()
      ↓
[等待中] 绘梨衣身上显示小气泡：「⏰ 30分钟后…」
      ↓
[提醒触发] 
  ├── ReminderWindow 弹出（Topmost, 无法 ESC/Alt+F4 关闭）
  ├── 绘梨衣切换到 Remind 动画：举便签本 ← 核心！符合性格
  ├── TTS 语音播报
  └── 开始计时（用于"忽略惩罚"）
      ↓
[用户点击「嗯，知道了」]
  ├── 弹窗关闭
  ├── 绘梨衣做确认后动画（松口气/微微笑）+ 气泡："帮到Sakura了…"
  ├── 如果在 3min 内确认 → 正常反馈 + stats++
  └── 如果超过 3min → "Sakura…没来呢。" → 下次互动变安静一次
```

## 二、弹窗 UI 设计

- 尺寸：360×200 px，圆角 16px
- 配色：米白底(#faf7f4) + 暖橙边框(#e07856)
- 不可关闭（无 X 按钮，无标题栏，ESC 无效，Alt+F4 禁用）
- 右上角小绘梨衣 idle 头像(48×48)
- 标题：「📋 绘梨衣的便签」
- 内容区：用户自定义文字
- 按钮：「嗯，知道了」（暖橙圆角按钮，hover 变深）
- 置顶：Topmost=true，全屏游戏时也能看到

## 三、绘梨衣性格适配

### 提醒触发动画
- 不是跳脚/焦急 → 不符合性格
- 是：举便签本（手里拿个小牌子，上面写提醒内容）
- 表情：Blush（微微脸红，打扰Sakura不好意思）
- 动作：轻轻挥手（Acknowledge 变体）

### 确认后俏皮话（随机）
- "帮到了Sakura…开心。"
- "提醒…送达了。"
- "Sakura真棒。"
- "……嗯。"（害羞）
- "下次也要记得。"

### 忽略惩罚（>3min）
- 提醒文字变成："……Sakura没来呢。"
- 确认后气泡："下次…早点来。"（仅一次）
- 下次 InteractiveLevel 临时降为 0 → 绘梨衣变安静
